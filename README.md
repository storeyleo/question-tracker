Question Tracker

Question Tracker is a repository for organizing and tracking questions over time. It is intended to provide a clear place to record questions, follow their progress, and keep useful answers or notes together.

## Project status

This project is still incomplete, although the Question Tracker is in a working state (unpolished).

## Intended use

The project is expected to support a question-tracking workflow such as:

- recording questions;
- keeping questions organized;
- tracking whether questions are open, answered, or otherwise in progress; and
- preserving answers, notes, or follow-up context.
