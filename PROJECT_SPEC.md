# Question Tracker

## Purpose

A Windows desktop application for organising university question
sheets, solutions and past papers, with functionality that makes
marking easier.

## Current requirements

### Module organisation

The application should organise material approximately as:

Module
- Problem Sheets
  - Problem Sheet 1
  - Problem Sheet 1 Solutions
- Past Papers
  - 2024/25

### Problem sheets and solutions

Problem sheets and their solutions can be manually linked.

The application does not need to automatically identify questions
or match questions between the problem sheet and solution PDF.

The main purpose of linking them is to make it convenient to display
the problem sheet and solution side by side while marking.
